# 手機 MVP 報告流程（約5分鐘）

1. 在 Android 手機開啟「活動待辦助理」，說明手機內含 OCR 模型與 Python 核心，Mac 不作辨識伺服器。
2. 匯入一張存在手機的活動海報；可關閉 Wi-Fi／行動數據展示本地辨識。
3. 查看原圖與草稿。展示日期、時間、地點，修正 OCR 誤字；沒有年份時說明只是建議年份。
4. 按「確認儲存」。在清單查看任務，示範編輯與完成狀態；重開 App 確認資料仍在。
5. 選取待辦任務，確認已允許通知與精準提醒，按「10秒後測試通知」，回到手機主畫面等通知。
6. 點通知回到 App，說明實際排程由 Android AlarmManager 負責，不依賴桌面程式保持開啟。
7. 有時間再展示拍照及貼上文字輸入。

可報告：手機內離線 OCR、Python 資料處理、SQLite 持久化與系統提醒的 MVP 流程。
不要宣稱：手機上已執行 Qwen VLM、所有海報均能完全正確辨識，或強制停止 App 後仍保證提醒。

相機拍照、相簿選圖與 OCR 結果仍受圖片清晰度、排版及字體影響；確認介面就是用來處理這些不確定資訊。
